# Scrcpy Plus 1.0.5-dev.4

开发预发布候选。目标平台为 Windows x64 和 macOS Apple Silicon，另提供独立 CLI/MCP 客户端。发布进度见[执行计划](../superpowers/plans/2026-11-25-release-1.0.5-dev.4.md)。

## 中文

- 在概览中选择 USB Android 设备，可管理应用、截图、使用 Shell 或 Logcat、检查进程与界面布局，以及调试前台应用开放的 WebView。可将 APK 拖入目标投屏窗口安装。
- 合并投屏保留每台设备的画面、工具栏和原有输入能力。切回独立窗口可继续原会话。Android 工具栏提供返回、主界面和音量加减；在画布上按 Shift+Tab 可聚焦工具按钮。
- 改善 USB iPhone 的 WDA 和 ReplayKit 连接恢复。若普通 USB 挂载开发者镜像时设备要求 RSD，助手将复用启动 Runner 的隧道挂载镜像。
- CLI 和 MCP 现提供 40 项操作，新增独立截图、前台 WebView 枚举和三项窗口布局或聚焦操作。独立包需要 Node.js 22.12 或更高版本，设备操作需要同机运行匹配版本的桌面应用。

开启 Beta Update 后，更新器可提示前往发行页手动安装。稳定渠道为 v1.0.4。开发期间的 macOS 真机检查覆盖多台鸿蒙设备拆分、Mi 10 Ultra 工具按钮和已配置的 USB iPhone 再次启动。Windows 真机、新 iPhone 首次签名、实际经过七天的续签，以及多用户 Android 安装归属和中断恢复仍待验证。[设备记录](../../RUNBOOK.md)

## English

- Select a USB Android device in Overview to manage apps, take screenshots, use Shell and Logcat, inspect processes and UI layouts, or debug a WebView exposed by the foreground app. Drop APK files onto the target mirror to install them.
- Merged mirrors retain each device's live view, toolbar and supported input. Splitting restores the original sessions. Android mirror tools provide Back, Home and volume controls. Press Shift+Tab on the canvas to focus the tools button.
- USB iPhone recovery handles WDA and ReplayKit interruptions. Devices that require RSD for their developer image can now mount it through the same tunnel used to launch the Runner.
- The standalone CLI and MCP client expose 40 operations, including standalone screenshots, foreground WebViews and three window layout or focus operations. The client requires Node.js 22.12 or later and a matching running desktop app for device operations.

Enable Beta Update to discover development releases and open the release page for manual installation. Stable Latest is v1.0.4. Earlier macOS hardware checks covered splitting HarmonyOS mirrors, Android controls on a Mi 10 Ultra and restarting a configured USB iPhone. Windows device workflows, first-time iPhone signing, renewal after seven elapsed days and interrupted multi-user Android installs still need hardware coverage.
